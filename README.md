# Лабораторные работы по ЭВМ

В данном репозитории представлены практические работы по дисциплине ЭВМ. Проект организован в виде монорепозитория и собирается с помощью системы CMake.

## Структура выполненных работ

### Лабораторная работа №1: Исследование внутреннего представления различных форматов данных
**Цель работы:** Знакомство с внутренним представлением типов данных, используемых компьютером.
* Разработан алгоритм ввода с клавиатуры требуемых типов данных (целые, вещественные).
* Реализован вывод внутреннего представления этих данных в двоичной системе счисления при помощи побитовых операций и масок.
* Написаны функции для обратного преобразования двоичного кода в исходный формат.

### Лабораторная работа №2: Исследование видеосистемы (текстовый режим)
**Цель работы:** Изучение работы с видеосистемой в текстовом режиме и освоение приемов использования цветовой палитры.
* Реализованы механизмы изменения цвета символов и фона.
* Настроено применение стилей как на всем экране, так и в пределах отдельно заданного окна.

### Лабораторная работа №4: Работа с клавиатурой и прерываниями DOS/BIOS
**Цель работы:** Изучение возможностей работы с клавиатурой через стандартные библиотеки C++ и средства систем прерываний.
* Разработана программа управления перемещением символа (например, `*`) в пределах заданного окна (координаты 20,10 - 60,20).
* Управление реализовано с помощью горячих клавиш (F3, F4) через стандартные функции C++.
* Произведена замена стандартных функций на системное прерывание `INT 21h`.

### Лабораторная работа №5: Аппаратные прерывания
**Цель работы:** Знакомство с различного вида аппаратными прерываниями и создание собственных подпрограмм обработки.
* Разработан алгоритм перехвата и подключения собственных обработчиков.
* Реализовано исполнение кастомных подпрограмм в единой цепочке со стандартными обработчиками системного таймера и клавиатуры.

## Сборка и запуск
1. Склонируйте репозиторий.
2. Установи Cmake (проверь команду в терминале ```cmake --version``` ,если выдает версию - иди дальше, иначе скачай Cmake ```https://cmake.org/download/``` 
3. Используйте `CMake` для генерации файлов сборки: 
```
cmake -S . -B build
cmake --build build
.\build\Lab_1\Debug\Lab_1.exe
```
4. Скомпилируйте проект через вашу среду разработки (Visual Studio / VS Code) или командную строку.
